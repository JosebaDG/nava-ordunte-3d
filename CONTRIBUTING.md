# Contribuir

Gracias por ayudar a contar el Valle de Mena con rigor y respeto.

## Tipos de contribución

- Errores reproducibles en dispositivos o navegadores.
- Rutas propias con permiso de publicación.
- Información histórica acompañada de fuentes.
- Fotografías o vídeo con autoría y licencia claras.
- Mejoras de código, accesibilidad, rendimiento o documentación.

## Antes de publicar datos

1. Elimina datos personales que no sean necesarios.
2. No señales accesos privados ni elementos patrimoniales vulnerables.
3. Indica autor, fecha, procedencia y licencia.
4. Explica si el trazado es aproximado, histórico o verificado sobre el terreno.

## Pull requests

- Una mejora principal por PR.
- Describe el problema, la solución y cómo probarla.
- Incluye capturas para cambios visuales.
- No añadas dependencias, analítica o servicios externos sin justificar licencia, privacidad, peso y fallback.
